## 关键验证点

- **数据正确性**：齐套率按件数（含缺料行部分 credit）、匹配率按行、缺料行是否含未建档由共享 `summarizeBom()` 统一；验证脚本用公式重算与接口返回值比对。
- **破坏性操作防护**：恢复预演不写库、非法备份返回 400、导入撤销只删除本批次对象、重复撤销被拒。
- **库存一致性**：入库/出库/移动后 `totalQuantity` 与批次合计一致；FIFO 按创建时间扣减；移动不改数量。
- **可追溯性**：流水含 `source / beforeQty / afterQty`，审计日志覆盖出入库、移库、导入、撤销、恢复。
- **界面**：每个模块的关键组件、关键词文本、无控制台错误；`Ctrl+K` / `Ctrl+I` / `Ctrl+S` / `?`、右键菜单、明暗主题切换均实测可用。

## 验证发现的缺陷与修复

| 缺陷 | 证据 | 处理 |
| --- | --- | --- |
| `server/domain/qr.js` 完整模式只判断 `origin` 非空，未判断公网，会把 `http://127.0.0.1:5173` 写进二维码详情链接；与「仅公网追加」的设计注释不符。前端 `LabelPrintView` 做了过滤，但领域函数直接调用时不安全 | `buildPartQrText(..., { mode:'full', origin:'http://127.0.0.1:5173' })` 输出含本地地址 | `qr.js` 器件码与库位码统一改用 `isPublicOrigin(opts.origin)` 判定；`tests/unit/run.mjs` 新增 2 条单测锁定。修复后模块验证 98/98、单测 158/158 |
