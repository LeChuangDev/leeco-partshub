### 技术栈与结构
- 前端：Vue3 + Vite + Naive UI + Pinia（静态产物）；xlsx 本地解析，qrcode 生成位置二维码。

- 存储：shared/kv.js 抽象（EdgeOneKV 适配器 / 本地 FileKV），命名空间 leeco-partshub，前缀 category:/part:/stock:/location:/transaction:/index:* 按规格实现。
- 本地开发：dev/server.mjs（Node http 复用 router + FileKV，注入 AUTH_TOKEN=dev-leeco-token），vite.config 代理 /api→8787。
- 部署：edgeone.json 描述（构建命令/输出/dist、KV 绑定 KV、环境变量 AUTH_TOKEN）。

### 已实现模块
